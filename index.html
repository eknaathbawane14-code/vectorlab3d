Step 01 • Breaking Down Language

Tokenization

Computers cannot read raw paragraphs directly. The very first step in Natural Language Processing (NLP) is tokenization: splitting raw text into smaller, discrete building blocks called tokens.

Why Divide Text into Tokens?

Neural networks only process numbers. By breaking sentences into standardized pieces—words, subwords, or characters—a model can look up each piece in a finite dictionary and convert text into a sequence of integers.

Comparing Tokenization Granularity

  • Word-level: Splits on spaces & punctuation. Simple, but struggles with unknown or misspelled words.
  • Subword-level: Keeps common words intact and splits complex words into roots + suffixes (e.g., change + ##ing).
  • Character-level: Splits text into individual letters. Smallest vocabulary, but sequences become very long.

Step 02 • The Numerical Lookup Table

Vocabulary

A vocabulary in NLP is the complete dictionary of unique tokens a model knows. Every token is assigned a unique integer called a Token ID so text can be indexed into numerical arrays.

What is an NLP Vocabulary?

Just like a phonebook maps names to phone numbers, a vocabulary maps every known word, subword, or punctuation mark to a fixed integer index from 1 to V.

Why Token IDs Matter

A Token ID is used as a row index to look up that token's embedding vector inside the model's embedding matrix. Without a consistent ID, the model wouldn't know which row to fetch.

Step 03 • Capturing Semantic Meaning

Word Embeddings

A Token ID like 24 or 37 is just an arbitrary label—it tells us nothing about what a word means. An embedding replaces each Token ID with a rich list of numbers (a vector) where each dimension captures a nuance of meaning.

Token ID vs. Embedding Vector

In the vocabulary, King might be ID 2 and Queen might be ID 3, while Apple is ID 6. You cannot do math on IDs (ID 2 + ID 3 ≠ ID 5).

An Embedding Vector places each word on multiple continuous scales—such as Royalty, Humanity, Technology, Food, Mobility, and Nature—so words with similar meanings have similar coordinates!

What Do Vector Dimensions Represent?

Each number in an embedding vector measures how strongly a word relates to a latent concept. For example:

King → [Human: 0.92, Royal: 0.96, Tech: 0.05]
Queen → [Human: 0.93, Royal: 0.95, Tech: 0.05]
Laptop → [Human: 0.04, Royal: 0.02, Tech: 0.96]

Step 05 • Measuring Semantic Closeness

Closest Pairs & Cosine Similarity

How does a machine know that King is closer to Queen than to Apple? It measures the angle between their embedding vectors using Cosine Similarity.

The Cosine Similarity Formula

Cosine Similarity = (A · B) / (||A|| × ||B||)
  • Dot Product (A · B): Multiplies matching coordinates of vector A and vector B and sums them up: ∑(Aᵢ × Bᵢ).
  • Vector Magnitude (||A|| × ||B||): The length of each vector from the origin √∑(Aᵢ²). Dividing by length ensures we only compare direction, not arrow length.
  • Similarity Score: Ranges from +1.00 (pointing in the exact same direction) to 0.00 (unrelated / 90° perpendicular) to -1.00 (opposite).
